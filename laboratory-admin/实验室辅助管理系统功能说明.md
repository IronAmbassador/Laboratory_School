# 实验室辅助管理系统功能说明

## 系统概述
基于Vue.js的实验室安全检查与管理平台，支持多角色权限管理，提供实验室信息管理、安全检查登记、数据统计等核心功能。

## 用户角色权限

### 超级管理员（roleId=1）
- 系统管理（用户管理、日志管理）
- 实验室管理（实验室信息维护）
- 安全检查登记（日常检查、异常处理）
- 数据统计展示
- 快捷导航功能
- 系统消息查看

### 实验室管理员（roleId=2）
- 实验室管理（实验室信息查看）
- 安全检查登记（日常检查、异常处理）
- 数据统计查看

### 普通用户（roleId=3）
- 实验室信息查看
- 基础安全检查功能

## 技术架构

### 前端技术栈
- Vue.js 2.6.10（核心框架）
- Element UI 2.15.14（UI组件库）
- Vue Router（路由管理）
- Vuex（状态管理）
- ECharts 5.5.1（数据可视化）
- Axios（HTTP客户端）

### 项目结构
#### API层
- 实验室API（lab/index.js、lab/sub.js）
- 安全检查API（device/index.js、device/repair.js）
- 系统管理API（sys/user.js、sys/login-log.js）
- 登录认证API（login.js）

#### 组件层
- 布局组件（Layout）
- 通用组件（Breadcrumb、Hamburger、SvgIcon）
- 业务组件（各功能模块组件）

#### 路由管理
- 静态路由（登录、注册、404）
- 动态路由（基于权限生成）
- 权限控制（路由守卫）

#### 状态管理
- 用户状态（登录信息、权限信息）
- 权限状态（菜单权限、操作权限）
- 应用状态（全局配置）

### 权限控制机制
- 基于角色的访问控制（RBAC）
- 动态菜单生成
- 页面级权限控制
- 功能级权限控制

## 数据库设计

### 核心数据表
- lab_info（实验室基本信息）
- lab_sub（实验室分室信息）
- lab_device（安全检查记录）
- lab_device_repair（异常处理记录）
- lab_user（用户信息）
- lab_login_log（登录日志）
- lab_operation_log（操作日志）

### 数据关联关系
- 实验室 → 分室（一对多）
- 分室 → 检查记录（一对多）
- 检查记录 → 异常处理（一对多）
- 用户 → 操作日志（一对多）

## 业务流程

### 用户登录流程
- 身份验证
- 权限获取
- 菜单生成
- 路由配置

### 安全检查流程
- 选择学期和实验室
- 选择检查项目
- 记录检查状态
- 异常情况处理
- 生成检查报告

### 异常处理流程
- 异常记录创建
- 处理人员分配
- 处理过程跟踪
- 状态更新确认

### 数据统计流程
- 实时数据采集
- 图表可视化展示
- 报表生成导出
